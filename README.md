# 균열의 투기장 · RIFT / TWENTY

## 현재 코드 구조 — TypeScript / OOP

수정할 원본은 **`src/`**, 브라우저용 빌드 결과는 **`public/src/`**입니다. 기존 `public/src/*.mjs`를 직접 수정하면 다음 빌드에서 덮어써집니다.

- [코드 구조·클래스·필드·메서드 브리핑](CODE_GUIDE.md)
- [현재 보스·직업·무기·유니크·합성 콘텐츠](GAME_CONTENTS.md)
- 전투 진입점: [`src/game.mts`](src/game.mts)의 `GameRun`
- 모델: [`src/entities.mts`](src/entities.mts)의 `Player`, `Boss`
- 전투 처리: [`src/systems/`](src/systems/)

```sh
npm install
npm run typecheck
npm test
npm start
```

`npm start`는 TypeScript 빌드 후 기존 5173 서버를 시작합니다. 이미 서버가 켜져 있으면 `npm run build` 후 새로고침하면 됩니다. TypeScript는 개발 의존성이며 게임 런타임은 기존 Canvas 2D + 표준 ES modules입니다.

게임 모델·콘텐츠·전투·기믹을 TypeScript로 옮겼습니다. 화면·그림·오디오 모듈은 `src/*.mjs`에 유지하며 빌드 시 출력 경로로 복사합니다. 아래 기존 상세 기록에서 `public/src/*.mjs`는 이제 빌드 결과를 뜻합니다. 최신 소스 위치와 타입 검사 범위는 `CODE_GUIDE.md`를 기준으로 읽으세요.


PC 브라우저용 2D 보스 러시. 잡몹·탐험 없이 **20번의 보스 결투**에 집중합니다.
Canvas 2D, JavaScript ES modules, Node 표준 라이브러리를 사용합니다. 외부 패키지·런 저장은 없습니다. 사용자 승인에 따라 라이선스를 확인한 관현악 음원과 석재 재질을 로컬에 포함합니다. [출처·라이선스](public/credits.html). 공유 완주 랭킹만 서버에 저장합니다.

## 실행

Node 24 이상 권장. 설치 과정 없음.

```sh
node scripts/serve.mjs            # http://127.0.0.1:5173/
node scripts/serve.mjs --port 8080
```

서버는 `127.0.0.1`에서 `public/` 게임과 랭킹 API(`/api/leaderboard/v2`, 이전 버전 `/api/leaderboard`)를 제공합니다. 경로 이탈·숨김 파일·외부 심볼릭 링크를 차단합니다.

## 첫 접속과 공유 랭킹

**리소스 준비 → 메인 메뉴 → 게임 시작 → 직업 선택** 순서입니다. 로딩 중에는 미완성 선택창을 노출하지 않습니다. CSS와 전투·그림 모듈, 전장·메인·보스 아틀라스 디코드를 완료하고 Canvas를 준비한 뒤 메인을 표시합니다. 메인·전장·20보스는 프로젝트용 생성 일러스트이며, 캐릭터와 전투 효과는 Canvas로 그립니다. 가짜 로딩률은 없습니다. 실패하면 **다시 불러오기**를 누르세요.

메인의 **랭킹**은 서버에 등록된 상위 100완주 기록을 표시합니다. 랭킹 통신 실패가 게임 시작을 막지는 않습니다.

- 실전 20보스 완주 후 결과 화면에서 닉네임을 입력하고 **기록 공개 등록**을 눌러야 게시됩니다. 연습·중도 시작·사망 기록은 UI에서 등록할 수 없습니다.
- **피격 횟수 적은 순 → 동률이면 보스당 평균 전투시간 짧은 순**. 평균은 전투시간 ÷ 20이며 소개·정지·클리어·보상 대기는 제외합니다.
- 보호막에 막힌 적 공격도 피격입니다. 무적으로 피한 공격은 제외하며 자기장은 연속 노출당 1회입니다.
- 닉네임·직업·무기·기록은 공개됩니다. 개인정보를 입력하지 마세요. 로그인 없이 완주별로 등록하므로 같은 닉네임이 같은 사람이라는 보장은 없습니다.
- **비공식 테스트 랭킹입니다. 브라우저 제출값의 형식만 검사하며 실제 승리·무조작을 서버에서 검증하지 않습니다.** 경쟁 상품·공식 순위용이 아닙니다.

새 전투 기록은 `/api/leaderboard/v2`와 `data/leaderboard-v2.json`을 사용합니다. 이전 `/api/leaderboard`와 `data/leaderboard.json`은 그대로 보존하며 순위를 합치지 않습니다. 서버 코드를 적용하려면 실행 중인 게임 서버를 재시작해야 합니다. 기록 파일은 모두 정적 공개 폴더 밖에 있습니다. 서버 재시작 후에도 유지되지만 상위 100위 밖 기록은 보관하지 않습니다. 동시 저장은 직렬 처리하며 임시 파일→rename으로 교체합니다. 손상된 저장소는 덮어쓰지 않고 오류를 반환합니다. 단일 서버용이며 여러 프로세스에서 같은 파일을 쓰면 안 됩니다.

POST는 게임과 같은 Origin·JSON·2KiB 이하 요청만 받습니다. loopback 프록시의 `X-Forwarded-Proto`만 HTTPS 종료 정보로 신뢰하며 외부 피어의 전달 헤더는 무시합니다. 신규 제출은 서버 전체 분당 10개, 대기 저장은 최대 10개입니다. 읽기와 동일 ID 재시도는 신규 등록과 구분합니다. 이 제한은 조작 방지나 인증을 대신하지 않습니다.

## BGM · 효과음

**첫 실제 클릭·키 입력 후 재생**됩니다. 모든 음원은 프로젝트의 로컬 파일입니다.

- 메뉴와 전투에 서로 다른 **8개 원곡**을 배정했습니다. 전투 7종은 철문·추격·용광로·빙하·폭풍·심연·최종전 분위기에 맞춰 20전장과 연결합니다. 기존 두 곡을 속도만 바꾼 편곡은 사용하지 않습니다.
- 일반 격파 **1.2초**, 최종 승리 **2.6초**. 녹음된 종결 화음을 짧게 감쇠하고, 인코딩 여백이 없는 WAV로 저장했습니다. 종료 후 메뉴곡, 보상·소개 되돌리기에서 재시작하지 않습니다.
- 기본·변형 무기 **23개 사운드 프로필**, 녹음 기반 전투 효과음27개. 칼날·옷자락·타격·활시위·총성·불꽃·물·돌·마법을 구분하고 발사음과 명중음을 분리했습니다. 충전·탄성권·잔상·파편·수압 폭발·Q 반격도 실제 이벤트와 연결합니다.
- Kenney, rubberduck, North Fantasy Music 등의 CC0 / CC BY / CC BY-SA 음원을 편집했습니다. [제작자·라이선스](public/credits.html), [파일별 출처·편집·해시](public/assets/audio/v5-sources.json), 제작 코드 `scripts/build-audio-v5.mjs`를 포함합니다.

피격 시 BGM을 잠깐 낮춥니다. 메인 또는 Esc 정지 메뉴에서 음량·음소거를 조절합니다. 초기 음량45%, 설정은 현재 페이지에서 유지됩니다. 정지·창 이탈·숨긴 탭에서는 효과음까지 중단하며 음악 위치를 보존합니다.

긴 음악 디코드 버퍼 최대3개, 짧은 종결음2개와 효과음30개(새27개 + 기존 회피 등3개). 전체 활성 음원 최대64, 반복 음악 타이머0. 전장 소개에서 다음 음악을 준비하고 오래된 음악은 버립니다. 음원 실패는 전투를 막지 않으며5초 뒤 다음 입력에서 재시도합니다. 소리 끄기→켜기로 즉시 재시도할 수 있습니다.

## 플레이

메인의 **게임 시작**을 누르세요. 처음이라면 직업 선택창의 **이 직업으로 연습**을 누르세요. 선택한 직업·무기로 이동 → 명중 → 회피를 익힙니다. 직업별 회피와 충전·재장전도 안내합니다.

연습 보스는 느리게 공격하며 피해는 3입니다. 맞아도 HP1 아래로 내려가지 않고 자기장·기믹·보상은 없습니다. 세 조작을 익힌 뒤 보스를 쓰러뜨리면 연습 완료. 언제든 선택창으로 돌아올 수 있으며 실전 체력·각인·진행도에는 영향이 없습니다.

1. 직업·무기 선택 → 보스 소개 → **결투 시작**. 소개 중 전투·자기장 시간은 정지합니다.
2. 고정된 공격 범위의 충전을 읽고 이동·공격합니다. **100%에서만 해당 공격이 발동**합니다.
3. 처치하면 **최대 생명력의 10% 회복**. 잔혹한 행운의 회복은 추가 적용하며 최대 체력을 넘지 않습니다.
4. 1~19번째 처치 후 **클리어 화면을 약1.5초 표시한 뒤 카드가 자동으로 나옵니다**. 카드 3장 중 하나를 고르면 다음 소개에서 미리 볼 수 있습니다. **뒤로** 돌아가 같은 제안에서 다시 선택 가능. 다음 결투 시작 때 확정됩니다. 되돌리기로 회복·각인·재추첨을 중복 획득할 수 없습니다.
5. 20번째 보스 처치 → 최종 승리. 사망·런 포기 → 진행도·각인 초기화.

클리어 중 전투·자기장은 정지합니다. 창을 벗어나거나 탭을 숨기면 클리어 대기도 멈추고, 돌아오면 남은 시간부터 이어집니다. 소개에서 보상으로 되돌아갈 때는 클리어 화면을 반복하지 않습니다.

보상 화면 최초 600ms와 이전부터 누르고 있던 선택 입력을 차단합니다. 가드 안에서 시작한 클릭/키 입력은 시간이 지난 뒤 놓아도 선택되지 않습니다. 입력을 놓고 새로 누르세요.

| 직업 | 무기 | 전투 / 회피 |
|---|---|---|
| 전사 | 검 · 창 · 도끼 | 베기 · 찌르기 · 강타 / 일반 회피 150 |
| 궁수 | 활 · 석궁 | 충전 후 놓거나 완충 자동 발사 / 긴 구르기 220 |
| 마법사 | 불 · 물 · 번개 | 단발 · 3중첩 수압 폭발/보호막 · 속사 / 즉시 순간이동 185 |
| 총술사 | 리볼버 · 저격총 | 6발/2발 탄창, 자동 재장전 / 사격 가능한 구르기 145 |
| 격투가 | 펀치 · 킥 | 직선 펀치 3연계 · 직선 킥 2연계 / 85 돌진 후 .45초 안에 새로 누르면 한 번 더 |

거리는 논리 좌표 기준. 모든 회피는 시작 부분에만 짧은 무적이 있습니다. 총술사도 구르기로 탄약·재장전을 우회할 수 없습니다. 궁수 회피는 충전을 취소합니다.

### Q 반격과 회피의 대가

아웃복서와 철벽반격, 각각을 포함하는 합성8종은 **Q가 별도 반격 키**입니다. 조준 방향으로 아웃복서0.22초 / 철벽0.28초 받아내며 성공 즉시 직선 반격합니다. 재사용은 각각2.8 / 3.2초. 뒤에서 오는 공격·지속 장판은 막지 못하고, 실패해도 재사용 시간이 적용됩니다. 반격 자세 중 공격·회피가 제한됩니다.

이 빌드들은 회피 거리20% 감소, 회피 재사용45% 증가, 연속 회피 불가입니다. SPACE와 Q의 원형 재사용 표시를 하단 중앙에 작게 나란히 보여줍니다. 일반 회피·좌클릭으로 자동 반격은 발동하지 않습니다.

### 각인과 합성 (v2)

보상 종류는 **일반·유니크·버서크** 세 가지입니다. 카드 상단에 종류를 표시합니다. 공격·속도·생존 등은 일반 카드의 세부 분류이며, 매번 세 종류가 한 장씩 나오는 규칙은 아닙니다.

기본 카드 12종, **직업별 유니크 5종 × 5직업 = 25종**, 버서크 3종입니다. 한 런에서 서로 다른 유니크는 **최대 2개**입니다. 첫 장은 단독 효과, 두 번째는 해당 쌍의 합성 공격으로 변경합니다. 획득 순서와 관계없이 같은 **50개 합성** 중 하나가 적용됩니다. 두 장 이후에는 유니크가 더 나오지 않습니다.

일반 보상은 유니크 **6%**, **5/10/15번째 특수 보스 보상에는 미보유 직업 유니크 1장 보장**입니다. 이미 2개가 있으면 대신 버서크 1장을 보장합니다. 다른 두 카드는 기본 각인으로 선택 여지를 남깁니다. 20번째 보스는 최종 승리라 추가 보상이 없습니다.

버서크는 유리 심장(피해 +30%, 최대 HP -20%), 노출(피해 +35%, 적에게 받는 피해 +25%), 피의 대가(피해 +40%, 회복량 -50%)입니다. 피해 보너스끼리는 더하며, 이동 거리나 회피 무적을 깎지 않습니다. 체력 각인과 최대 HP 감소는 획득 순서에 영향을 받지 않습니다.

샷건 + 대포는 포탄이 명중하거나 사거리 끝에 도달하면 산탄 5발을 뿌립니다. 잔상·파편·마무리·화상은 다시 추가타를 발동하지 않습니다. 산탄과 연사 묶음의 각인·중첩 횟수는 주 공격 한 번당 한 번입니다. 돌려받는 투척검은 왕복 각각 한 번 피해를 주지만 명중 각인은 한 번만 발동합니다.

**기본 물 무기**는 둔화로 거리를 유지하고, 4초 안에 주 공격3회를 적중하면 90% 추가 수압 폭발과 보호막8을 얻습니다. 물 자체 보호막 상한16, 중첩 간 최소0.35초, 잔상은 중첩 제외입니다. **대마법사**는 물 폭발을225%, 보호막을12로 강화합니다. 불은 강화 화상, 번개는 주 공격당25% 확률로2.5배 치명타입니다.

선택창에서 직업 능력치·유니크의 효과와 대가·합성 10가지를 확인할 수 있습니다. 두 번째 유니크 보상에는 합성 결과가 표시되며, 다음 보스 소개에서 미리 보고 되돌릴 수 있습니다.

| 직업 | 기본 최대 HP | 적 공격 피해 감소 |
|---|---:|---:|
| 전사 | 120 | 12% |
| 궁수 | 95 | 0% |
| 마법사 | 90 | 0% |
| 총술사 | 100 | 0% |
| 격투가 | 110 | 6% |

감소율은 보호막을 소모하기 전에 적용합니다. 자기장 피해는 직업 방어율·보호막·회피 무적을 우회합니다.
